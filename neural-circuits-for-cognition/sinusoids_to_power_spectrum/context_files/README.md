# context_files — sinusoids_to_power_spectrum

**Self-contained:** everything needed to build this video is in these files, plus the area
module `neural-circuits-for-cognition/prescott2008.py` (palette, impedance, caching). Do not
open the deck folder listed in `SOURCES.local.md`; it is read-only, and nothing in it is needed.

- `contract.md` — the build contract: header, purpose, must/must-not, colours, layout in frame
  units, beat sheet with every caption verbatim, end frame, acceptance checks.
- `model.md` — the signal recipes (seeds, sample rates, Welch settings), verified numbers, and
  the asserts for `main.py`.
- `science.md` — the concepts in plain words, where the video sits in the talk, the speaker line
  and likely questions.
- `style.md` — the delivery format, look, colour roles, text/stroke floors and ManimGL 1.7.2
  footguns. It is shared by the four Prescott-deck videos; don't edit it here.

Provenance labels cited (see `SOURCES.local.md`): deck spec (slide 1; Video production notes),
deck manifest, deck model module. All were read 2026-09-30.
