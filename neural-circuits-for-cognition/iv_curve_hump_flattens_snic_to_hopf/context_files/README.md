file needs to be opened.

  data mapping, continuity, accuracy flags, acceptance checklist.
- `science.md` — the concepts (steady-state I–V, the hump, SNIC vs Hopf in words), the slide's
  framing and speaker lines, paper numbers, likely audience questions.

  element is computed, paste-ready reference code, and verified key numbers to assert.
- `style.md` — shared look and colour roles for all Prescott-deck videos (do not edit here).
